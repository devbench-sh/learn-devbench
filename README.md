# Learn DevBench

Practice pages made in the Learn DevBench tour: everybody who joins an organization on [DevBench](https://devbench.sh) gets a
workspace where an agent shows them how work goes, and the change it makes there is one small page in this repository.

- **Public.** Anyone can read it. The pages are made up and neutral: no names, companies or anything real.
- **One file each.** `learn/<number>.html`, on its own branch `learn/<number>`, merged into `practice` by the person who asked for it.
  `main` holds only this README, [`HOW-TO-DRAFT.md`](HOW-TO-DRAFT.md) and [`template.html`](template.html).
- **Plain HTML and CSS.** One screen, no scripts, nothing loaded from elsewhere. DevBench checks every push.

Commits are written as "Learn DevBench". Pull requests from outside are closed unread.
